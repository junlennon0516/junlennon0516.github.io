X-ray 이상 탐지 결과를 **처방 추천 → 문헌 검증 → 재추천**으로 연결한 의료영상 AI 보조 진단 프로젝트입니다. 의료진이 영상 히트맵과 추천 근거를 함께 검토할 수 있는 프로토타입을 4인 팀으로 구현했습니다.

## 담당 역할

**ArangoDB 그래프 데이터 구축을 주로 담당**했습니다. 방문·상병·처방 관계의 co-occurrence 엣지 설계, 데이터 적재와 유사 환자군 분석을 위한 데이터 구성에 기여했습니다.

백엔드 API 개발, 성능 평가와 통합 테스트에도 참여했습니다. 아래 구현 기능과 평가 수치는 팀 전체 결과입니다.

## 핵심 구현

| 구성 | 역할 |
| --- | --- |
| X-ray 분석 | 이상 영역 히트맵과 질병 예측 결과 제공 |
| 그래프 기반 추천 | ArangoDB의 유사 환자군·처방 이력과 현재 진료 정보를 결합 |
| 비동기 검증 | RabbitMQ로 검증 작업을 분리하고 PubMed 문헌 근거 확인 |
| 결과 설명 | 추천 사유와 실행 경로를 제공하고 부적절 판정 시 재추천 |

Spring Boot 업무 API와 독립적인 Python AI 서비스를 REST API로 연결했습니다. 프론트엔드, API, AI 서비스와 데이터베이스·메시지 브로커는 Docker Compose로 통합 실행하는 구조입니다. 진단서 초안 생성과 환자·진료 이력 관리도 구현했습니다.

## 평가 결과와 개선점

| 팀 평가 항목 | 결과 |
| --- | --- |
| 그래프 통계 기반 처방 적정성 분류 | Calibration Set AUC **0.860** |
| 에이전트 호출 경로 정확도 | 50개 시나리오 기준 F1 **0.924** |
| 추천 답변 품질 | LLM 평가 점수 **0.386** |
| 할루시네이션 발생률 | 50개 시나리오 중 45개 · **90%** |

호출 흐름은 비교적 정확했지만, 추천 근거와 처방명·코드가 연결되지 않는 문제가 남았습니다. 근거 밖 처방 생성 제한, 코드 검증과 근거 부족 시 응답 보류가 주요 개선 과제입니다. 위 수치는 보고서의 개발 평가 결과이며 임상 진단 정확도를 의미하지 않습니다.

이 프로젝트를 통해 **서비스 연동의 정상 동작과 AI 답변 품질을 별도로 검증해야 한다는 점**을 배웠습니다. 그래프 데이터의 구조와 품질이 추천 근거에 미치는 영향을 확인하고, 실행 경로와 결과를 함께 평가했습니다.
